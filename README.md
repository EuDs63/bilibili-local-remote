# 网页视频床上遥控器

在同一个 Wi-Fi 下，用手机遥控 Windows Edge/Chrome 中正在播放的网页视频。所有通信只在局域网内进行，不使用云服务器。

扩展会自动控制当前正在播放、正在发声或最近控制过的视频标签页。YouTube、哔哩哔哩等使用标准 HTML5 `<video>` 的网站可直接使用；其他采用 HTML5 播放器的网站也能使用播放、暂停、进度、音量和倍速等通用功能。

## 已实现

- 播放、暂停、快进/快退 10 秒
- 拖动播放进度、音量与静音
- 0.5×—2× 倍速切换
- 上一集、下一集；网站不支持选集时自动切换为快退/快进 1 分钟
- 播放器全屏
- 从手机关闭当前受控的视频标签页
- B 站弹幕开关等站点增强功能
- 手机显示视频标题、进度和播放状态
- 从手机发送任意 HTTP/HTTPS 视频链接到电脑
- 自动识别带标题的完整分享文案，例如 `Watch this: https://www.youtube.com/watch?v=xxxx`
- 启动窗口显示二维码，手机扫码打开
- 支持安全配对模式和免配对模式

## 第一次安装 Edge 扩展

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目中的 `extension` 文件夹。

Chrome 的扩展页面是 `chrome://extensions`，其他步骤相同。

扩展需要“读取和更改所有网站上的数据”权限，才能发现并控制不同网站中的播放器。它只读取播放器状态，并只把状态发送到本机的 `127.0.0.1:17331` 服务。

扩展文件更新后，需要在扩展管理页面点击一次“重新加载”，再刷新现有的视频标签页。

## 无痕/InPrivate 模式

扩展代码兼容 Edge InPrivate 和 Chrome 无痕窗口，但浏览器默认不会允许扩展在这些窗口中运行，需要手动开启：

- Edge：打开 `edge://extensions`，进入扩展“详细信息”，开启“允许 InPrivate”。
- Chrome：打开 `chrome://extensions`，进入扩展“详细信息”，开启“在无痕模式下启用”。

启用后，请重新打开或刷新无痕窗口中的视频页面。普通窗口和无痕窗口会连接同一个本地 `17331` 服务，并共享当前受控标签页状态；视频标题和页面地址也会显示在本机启动终端的运行日志中。

## 推荐：免配对启动

双击 `start-no-pairing.cmd`。启动窗口会显示手机访问地址和二维码，安卓手机直接扫码即可，不需要输入配对码。

免配对模式意味着：同一个局域网内知道访问地址的设备都可以控制播放器，也可以让浏览器标签页打开任意 HTTP/HTTPS 链接。建议只在可信的家庭 Wi-Fi 中使用；共享网络请使用配对码模式。

正式入口始终是：

```text
http://电脑局域网IP:17331/
```

例如 `http://192.168.x.x:17331/`，不再需要添加 `?v=2`。

## 可选：配对码启动

如需限制其他局域网设备，双击 `start.cmd`。手机扫描二维码打开页面后，再输入窗口显示的六位配对码。

## 每天使用

1. 双击所需的启动脚本，保持黑色窗口开启。
2. 确认终端出现 `[扩展] 已连接，正在监听遥控命令`。如果没有，前往扩展管理页重新加载扩展。
3. 在 Edge 打开或刷新一个视频页面。终端识别成功后会打印 `[播放器]`、标题和页面地址。
4. 手机扫描窗口中的二维码，或打开收藏的 `http://电脑局域网IP:17331/` 地址。
5. 在“打开视频”输入框中粘贴纯链接，或粘贴包含 HTTP/HTTPS 链接的完整分享文案，然后点“打开”。

“打开视频”会优先复用当前受控的视频标签页；还没有受控标签页时，会复用当前活动标签页或创建新标签页。

## 如何阅读启动终端日志

发送链接后，正常流程会依次出现：

```text
[命令] #1 已入队：打开链接 https://example.com/video
[命令] 已发送到扩展：#1
[命令] #1 执行成功：已在标签页 123 打开链接
```

- 看到“扩展未连接，命令不会进入队列”：重新加载浏览器扩展，并刷新已有视频页面。
- 只有“已入队”，没有“已发送到扩展”：扩展后台没有继续轮询，请重新加载扩展。
- 显示“执行失败”：终端会附带浏览器返回的原因，例如没有可控制的标签页或页面不允许扩展运行。
- 已显示“执行成功”但页面无法加载：命令链路正常，需检查目标网站、网络或代理状态。

扩展离线时，手机页面现在会直接显示错误，链接不会再被静默放入无人处理的队列。

首次启动时，如果 Windows 防火墙询问是否允许访问，请只勾选“专用网络”。

## 安装依赖与开发检查

当前电脑已安装所需依赖。如果复制项目到另一台电脑，先在项目目录运行：

```powershell
npm install
```

检查命令：

```powershell
npm run check
npm test
```

播放、进度、音量和倍速直接使用浏览器的 HTML5 媒体接口，兼容性最好。“上一集”“下一集”“弹幕”和站点播放器自己的全屏按钮依赖页面结构；网站改版后可能需要同步更新扩展里的页面选择器。不使用 HTML5 `<video>`、禁止扩展运行或带有特殊 DRM 限制的页面可能只支持部分功能。
